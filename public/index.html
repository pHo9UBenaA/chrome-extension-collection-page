Extensions

  1. Window Merger

    Put all windows into one window with a shortcut. Tab groups and pinned tabs stay in place.

    View in the Chrome Web Store

  2. Pin Switcher

    Pin or unpin the current tab with a shortcut.

    View in the Chrome Web Store

  3. Tab Cloner

    Open a copy of the current tab with a shortcut.

    View in the Chrome Web Store

  4. Reading List Register

    Add the current tab to your Reading List with a shortcut.

    View in the Chrome Web Store

  5. Domain Tab Organizer

    Put tabs from the same website into groups with a shortcut.

    View in the Chrome Web Store

  6. Tab Cleaner Extension

    Close tabs from websites on your saved list.

    View in the Chrome Web Store
